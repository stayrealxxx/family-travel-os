# Family Travel OS

一个手机优先的家庭旅行手册网页。

当前旅行：**West Coast Christmas 2026**

- 2 adults + 2 children
- 2026-12-23 → 2027-01-02
- San Jose + Thousand Oaks / Los Angeles
- Route A–D 对比
- 倒计时、路线图、逐日时间表、地图导航、待办状态、深色模式

## 隐私

这是公开网页。不要提交：

- 航班 / 酒店确认号
- 票号
- 护照或证件号
- 信用卡信息
- 家庭完整住址

## 更新

当前版本是单文件静态网页：`index.html`。修改后直接提交到 `main` 即可。
